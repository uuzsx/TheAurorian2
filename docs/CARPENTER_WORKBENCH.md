# 木匠工作台

注册名 `theaurorian2:carpenter_workbench`，中文“木匠工作台”，英文“Carpenter's Workbench”。位于创造模式的极光工作台旁。目前是可摆放的装饰方块，未分配制作、储物、交互界面或合成配方。

模型来自用户提供的 Magic Store 铁匠家具包 `blacksmith_table_1_2x1`。保留原来的 18 个部件、图纸、台面工具、旋转枢轴和物品展示变换。贴图保持 256×256 的原像素密度、木纹和透明度，台体木材和锤子握柄共用同一套木材色阶，取自现用的 `aurorian_crafting_table_model.png`，锤头金属和图纸逐像素保留原贴图。

使用现有 `PairedFurnitureBlock` 的双格放置和拆除规则，占点击位置及玩家右侧一格。世界模型沿 X 平移 16，三块跨格台面在接缝处裁切并连续映射原 UV；中间窄横梁保留完整旋转 UV，归第一格渲染。其他部件只转换局部原点，物品模型和导出的 Blockbench 工程保留源坐标。

碰撞按原部件预计算并缓存四个方向，斜放工具采用外接长方体，纸张不增加碰撞厚度。不添加方块实体、tick、网络包或全局规则。只有第一半掉落工作台，另一半随相邻更新清除；阻挡右侧时不允许放置。

导入脚本：`scripts/import_carpenter_workbench.ps1`，通过项目 `Write-Json` 验证并压缩 JSON。预览、贴图和可编辑工程在 `exports/carpenter_workbench/`。原素材授权继续适用。

验证：解析所有导出 JSON，确认物品模型的几何和展示变换与原版一致，逐像素检查锤头与图纸所用 UV 区域不变；客户端实际加载、摆放和手持截图通过。专用服务器检查四个朝向、跨区块的左右双格、两半碰撞、任意一半拆除、创造/生存掉落以及右侧被阻挡时拒绝放置。
