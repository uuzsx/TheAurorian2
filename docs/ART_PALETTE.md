# The Aurorian 2 Art Palette

This file records reproducible palette presets rather than screenshot-only colors.

## Active Aurorian Grass

- Approximate normal-climate top color: `#33BAE1`
- Normal-climate colormap multiplier: `#FFFFFF`
- Character: the original clear moonlit blue-cyan artwork, without grayscale conversion
- Top color reference: `aurorian_grass_block_top.png`
- Side color reference: `aurorian_grass_block.png`
- Side reference average: `#2F9CD1`
- Plains multiplier (`temperature: 0.8`, `downfall: 0.4`): `#FFFFFF`
- Forest multiplier (`temperature: 0.7`, `downfall: 0.4`): approximately `#B8D4FF`

## Reserved Corrupted Aurorian Grass

- Approximate normal-climate surface color: `#2A98B8`
- Normal-climate colormap tint: `#3AD3FF`
- Tint-mask brightness scale: `1.15`
- Character: dim, cold cyan with a corrupted or decaying atmosphere

The active grass model uses the original colored top and side textures. The
normal climate multiplies them by white, while colder, warmer, wetter, and
drier climates apply small RGB multipliers generated by
`scripts/generate_aurorian_grass_colormap.ps1`. This preserves the source
texture's cyan, blue, and highlight relationships across biome transitions.

The grayscale masks generated by `scripts/generate_grass_tint_overlay.ps1`
are retained for the reserved corrupted-grass treatment and are not used by
the normal Aurorian grass block.
