## 基础规则

- 用于鱼钩位于极光维度、水中成功收竿的场景，其他维度维持原有钓鱼规则。通过 NeoForge 战利品修改器选择维度，单独复制这些战利品 JSON 不会自动切换钓鱼表。
- 每次成功获得战利品抽取一个类别，再从对应子表抽取一种物品，每份数量为 1。四种鱼虾均为现有生食物品，不是实体或装鱼桶。
- 参考项目依赖的 Minecraft 26.1.2 原版 `gameplay/fishing` 及 `fish`、`junk`、`treasure` 子表。
- 基础类别权重与原版相同：鱼获 85、杂物 10、宝藏 5；质量系数分别为 -1、-2、+2。
- 宝藏沿用原版鱼钩 `in_open_water` 条件。普通封闭小水池仍能获得鱼获和杂物，不能获得宝藏。
- 不增加昼夜、天气、具体群系或剧情门槛。正常咬钩等待和饵钓规则保留原版行为；饵钓不直接提高宝藏概率。

以下“总体概率”均指：成功钓到一次战利品、满足开放水域条件、海之眷顾与其他幸运修正均为 0 的情况。不是每次抛竿都保证获得物品，也不是有限次数内的保底结果。

## 幸运与开放水域

沿用原版有效权重：`max(floor(基础权重 + 质量系数 × 幸运值), 0)`。鱼获、杂物和宝藏子表内未设置质量系数，因此幸运只改变类别分布，不改变同一类别里各物品的相对比例。

| 条件 | 鱼获 | 杂物 | 宝藏 |
| --- | ---: | ---: | ---: |
| 开放水域，无幸运修正 | 85% | 10% | 5% |
| 开放水域，仅海之眷顾 I | 84.85% | 8.08% | 7.07% |
| 开放水域，仅海之眷顾 II | 84.69% | 6.12% | 9.18% |
| 开放水域，仅海之眷顾 III | 84.54% | 4.12% | 11.34% |
| 非开放水域，无幸运修正 | 89.47% | 10.53% | 0% |

玩家的其他幸运来源也可能影响结果，例如当前拐杖糖、生鱼片给予的幸运效果；上面的海之眷顾示例假设没有这些额外修正。
