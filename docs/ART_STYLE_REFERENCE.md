# 极光美术风格参考

根据 2026-09-08 的项目资源与已有用户反馈整理。这是对现有素材的观察和制作参考，不是新增剧情设定；用户后续的具体要求优先。

## 查看范围

- 当前命名空间下的 939 张 PNG 贴图，已按方块、物品、生物、界面和其他资源分组查看。
- 1,665 个普通模型 JSON，包含大量父模型引用、方块变体和物品引用，并非 1,665 个独立造型。
- 22 个 GeckoLib 几何模型、8 个动画文件、6 个 OBJ 模型，以及 9 个 Java 模型类。
- 普通模型中 174 个包含 elements（其中一个为空）；对非空显式几何及 GeckoLib 几何生成并查看了 195 张静态造型预览。
- 另外核对了 exports 中的 86 个 Blockbench 工程和 67 个 JSON 文件；这里包含历史方案与未接入的提案，当前游戏资源和用户最终选择优先。
- 静态研究预览用于判断轮廓与材质关系，不能替代游戏中的骨骼动画、光效、色调处理和实际显示变换验证。资源文件存在也不代表已注册或在游戏里启用。

## 总体印象

以 Minecraft 像素与方块造型为基础的冷色幻想世界。灰蓝、靛蓝和蓝紫建立安静的环境底色，青蓝植物、紫色晶体和浅色月亮元素建立视觉焦点。整体同时存在幽静森林、古老遗迹、月光与神秘魔法的气质。

环境材料多用克制的色阶，植物、矿物和魔法装备可以明显鲜亮。红、橙、金黄、灰绿等也存在，用于具体材质、花朵、火焰、食物、界面状态与特殊对象；不应把所有素材机械地改成同一种蓝色。

颜色与造型只用于美术判断。角色阵营、善恶、力量来源与剧情真相以 LORE_CANON.md 为准，不能由“亮色”“神圣外观”直接推断。

## 像素和纹理

- 353 张方块贴图中有 301 张为 16×16，294 张物品贴图中有 253 张为 16×16。基础像素密度接近原版。
- 生物、装备与复杂方块使用更大的 UV 图集。图集为 64、128、256 像素并不自动意味着高清风格，关键是落在模型上的单位像素密度和绘制方法。
- 保持硬朗、清晰的像素边界；检查放大图时使用最近邻采样。
- 木纹由连续色块、板缝和局部深浅变化组成；石纹以块面和裂缝体现结构；金属与晶体用明确亮边和面向区分。细节应帮助识别材质。
- 同一块材料上的纹理方向和 UV 比例应一致。大箱、大桌等长模型要重复或扩展木纹，避免把单格贴图直接拉长。
- 深色包带、把手、盖子下方与箱底可以有少量边缘磨损和明暗变化，避免大块无层次纯色；同时避免均匀铺满随机噪点。
- 小图标重视轮廓、暗边和少数亮点；很多物品在 16×16 下仍能识别刃部、柄、晶核或容器。

## 造型与层级

- 普通方块以立方体、柱体、台阶、面片为主，延续原版构造方式。
- 家具先明确桌面、腿、横撑、框架、盖子、包带等真实部件。模型需要通过厚度、凹凸、连接和侧面结构成立。
- 武器常用长柄、分段连接、尖角、护手、晶体刃与明确的收尖轮廓；现有月银工具的装饰密度明显高于木制工具。
- 仪式和魔法物件常见对称台基、立柱、晶核、环形、悬浮部件。重要物件可增加复杂度，但应保留一个主视觉焦点。
- 动物保留可识别的身体比例，以方块体积结合角、耳、尾和少量面片细化；特殊生物有更尖锐的肢体、晶簇与发亮部位。
- 骨骼按实际部件组织。已有动画包括持续旋转、悬浮、封印开合、分节肢体运动与短促攻击动作；后续动画需围绕物件功能和阅读顺序设计。

## 已确认的用户偏好

- 同系列、不同木材的家具采用一致的纹理结构与造型，只变木色。
- 椅子、桌子、凳子、木箱和板条箱的包带、包边及加固框使用对应原木侧面的树皮色阶，主体仍使用木板色阶。污秽木包带取树皮主体暗紫色，不把少量绿色附着斑放大成整片装饰。
- 采色应来自指定木板或材料贴图，不能凭印象近似。
- 用户重视 Minecraft 像素感，曾否定高清化、拉伸木纹、过多噪点和大片单调纯色。
- 模型需要有实际造型设计，不能仅把二维物品贴图加厚。
- 木凳和长桌的最新方案采用用户提供的 ShizuArt 中世纪浴室家具模型，保留原木纹、提孔和镂空，按对应木板采色；此前自制木凳、桌布长桌属于被替换的方案。靠背椅维持既有模型与树皮包边。
- 长凳和小方桌同样采用该素材包的 `banc`、`petite_table` 原模型，共用上述五种木板色阶贴图；保留长凳的低矮双格比例与小方桌的一格高度。
- 神圣、华丽的物件可以简约；应靠比例、轮廓、对称与集中装饰实现。用户不喜欢用大量长条纹或噪点代替神圣感。
- 木箱最终以 Wooden Pack 方案为准；此前的无锁版、旧款、污秽破损实验不是当前木箱的默认标准。
- 皎月箱目前属于独立模型提案，不能把该提案的复杂度直接套到普通木制家具上。

## 后续工作方法

开始制作时先选同类型现有素材作参照，提取原图色阶，再确定像素密度和主轮廓。小尺寸检查辨识度，近看检查板缝、边缘与 UV，最后核对四周和底面。涉及游戏实现时再验证朝向、尺寸、动画和客户端加载。

本次仅梳理与记录美术参考，没有改动已有模型、贴图或游戏实现。研究用总览图和清单位于本地忽略目录 `build/art-style-study/`。
