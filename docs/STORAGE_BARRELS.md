# 五木储物桶

用户选定的 Magic Store 铁匠家具 `blacksmith_barrel_1`、`blacksmith_barrel_3` 分别作为直立款和横放款，谧木、垂柳木、幽帘木、咒霜木、污秽木各两种，共十种物品。与已有取水木桶的注册名和用途分开。

## 外观与制作

- 原模型坐标、旋转中心、UV、物品展示变换和像素纹理保留；原五阶棕色映射对应木板，箍带保留原贴图的颜色与纹理。各木种共用相同几何和纹理图案。
- 两个公共模型分别保留原 1 号和 3 号几何；每种木材的子模型只覆盖贴图。Blockbench 导出保留原结构和嵌入贴图。
- 原 JSON 的 16 个 `#missing` 面对应 Blockbench 中没有贴图的内部面，已检查其外侧被其他立方体覆盖，运行时不导出这些面。
- 直立款保持直立；横放款随玩家水平朝向放置。碰撞形状匹配原模型，包括横放款的小幅坐标偏移。
- 六块对应木板、两块对应半砖合成一个直立储物桶：上下两行木板，中间一行左右放半砖，中间留空。该摆法避开原版木桶的通用配方。
- 在工作台中单独放入储物桶物品，可一比一转换为同木种的另一款。

## 储物实现

`AurorianStorageBarrelBlock` 继承原版 `BarrelBlock`，只补充外形、放置方向和模型类型编解码。通过 NeoForge 的 `BlockEntityTypeAddBlocksEvent` 将这十个子类方块添加到原版 `BlockEntityType.BARREL` 的合法方块集合，不替换原版逻辑。

直接使用原版 27 格菜单、库存与战利品表存档、改名、开关音效和 OPEN 状态、漏斗与物品传输能力、比较器信号、库存掉落。上方被实体方块盖住仍能打开，不合并成双桶。与原版木桶相同，可作 300 tick 燃料。

没有新的容器类型、方块实体类、常驻 ticker、自定义渲染器、Mixin 或网络包。打开时由原版安排短期检查，关闭后不持续运行。原模型没有开盖动画，OPEN 状态不改变模型几何。
