Aurorian Bird Blockbench Model

File: aurorian_bird.geo.json
Format: Bedrock Entity / GeckoLib geometry 1.12.0

Import this file into Blockbench with the Bedrock Entity format.
The model is standalone and is not connected to the mod registry or game code.
The front of the bird faces negative Z. The feet rest at Y=0.

Bones include:
- root, body, chest, neck, head
- beak_upper, beak_lower, eye_left, eye_right
- crest_center, crest_left, crest_right
- wing_left, wing_left_tip, wing_right, wing_right_tip
- tail_center, tail_left, tail_right
- leg_left, leg_right, foot_left, foot_right
- four toe bones

The geometry uses a 64x64 UV layout. The included aurorian_bird.png is a blue-purple
preview texture with a pale cyan chest and warm orange beak and feet.

After importing the geometry, load aurorian_bird.png in Blockbench's texture
manager and assign it to the model to preview the colors.
